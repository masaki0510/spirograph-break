# Spirograph Break

> 描き終わるまでが、休憩。

休憩用のアンビエントタイマーアプリ。スタートすると幾何学模様（スピログラフ）が自動で描かれ始め、**カウントダウンが 0 秒になる瞬間にちょうど描き終わる**。

**→ [https://masaki0510.github.io/spirograph-break/](https://masaki0510.github.io/spirograph-break/)**

---

## 使い方

1. 時間・描画モード・形・対称性を選ぶ
2. 「スタート」を押す
3. 眺めて、休む

| 設定 | 選択肢 |
|---|---|
| 時間 | 1分（テスト）/ 5 / 10 / 15 / 25分 |
| 描画 | 2D（平面）/ 3D（立体・自動回転） |
| 形 | 円 / 三角 / 四角 |
| 対称 | シンメトリー / アシンメトリー |

---

## 特徴

- **0秒で完成** — タイマーと描画が同じ時計を共有。早送りなし、模様は最後の1秒まで描き続ける
- **カタカタ音** — 定規とペンの音を Web Audio API で合成（ファイル不要）
- **3D モード** — 奥行きを持つ立体的な曲線がゆっくり自動回転
- **オフライン動作** — 単一 HTML ファイル、外部依存なし
- **モバイル対応** — ホーム画面に追加して擬似アプリとして使える

---

## 技術仕様

- 単一ファイル（`index.html`）— ビルド工程なし
- Canvas 2D + Web Audio API
- スピログラフの数学: エピサイクル（歯車ベクトルの足し算）
- 多角形の外枠は極座標で正確に表現（円近似ではない）
